Detailed Description

real_app.py — sends UDP traffic to the UT AppInterface.

Usage:
    python3 real_app.py [--target HOST] [--port PORT]
                        [--rate-kbps RATE] [--pkt-size BYTES]
                        [--duration SECS]

Defaults:
    target    127.0.0.1   (same Mininet host as the UT process)
    port      7000
    rate-kbps 1000
    pkt-size  1024
    duration  0           (0 = run forever)
