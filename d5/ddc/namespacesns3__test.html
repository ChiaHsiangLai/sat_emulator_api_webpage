def sns3_test.myNetwork (   num_uts = 1) 
Builds and starts the Mininet network.

Parameters
----------
num_uts : int
    Number of User Terminal (UT) hosts to create (default: 1).
    Each UT is assigned a unique IP in the 10.0.1.x subnet,
    starting from 10.0.1.10, and is connected to s1.

Topology overview:
  - Hosts: ut0, ut1, ..., ut(N-1), sat1, gw, ncc
  - Switches: s1 (left side, connects all UTs / SAT1 / GW)
              s2 (right side, connects GW and NCC)
  - 3 subnets enforce the routing path:
      10.0.1.x  ->  UT(s) <-> SAT1
      10.0.2.x  ->  SAT1  <-> GW
      10.0.3.x  ->  GW    <-> NCC

After starting the network, secondary IPs and static routes are
configured so that ALL traffic follows:
    UT(s) -> SAT1 -> GW -> NCC  (and the symmetric reverse path)
