# SNS3 Impl — Model API Docs

Doxygen-generated API reference for the `model/` directory (SNS3 satellite
network simulator implementation), in the style of https://www.sns3.org/api/index.html.

Regenerated from source with:

```bash
doxygen documentation/Doxyfile
```

(see the main project repo for the Doxyfile and source).

This repo contains only the pre-built static HTML output — open `index.html`
locally, or enable GitHub Pages (Settings → Pages → Deploy from a branch →
`main` / `/ (root)`) to publish it at a URL.
