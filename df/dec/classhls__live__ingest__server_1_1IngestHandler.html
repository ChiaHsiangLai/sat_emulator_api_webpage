def hls_live_ingest_server.IngestHandler._write_atomic (   self,
  dest,
  body 
)
private 
Write body to dest via a temp file + os.replace(), so a GET
handled by a different thread of this ThreadingHTTPServer can never
observe a partially-written file — a plain open(dest,"wb") truncates
dest to 0 bytes before the write completes, and live.m3u8 in
particular gets overwritten often enough (every successful push)
while being polled often enough (every ffplay playlist reload) that
a concurrent GET landing in that window would see a truncated/torn
file. os.replace() is an atomic rename on POSIX, so any GET sees
either the fully-old or fully-new file, never a partial one.
