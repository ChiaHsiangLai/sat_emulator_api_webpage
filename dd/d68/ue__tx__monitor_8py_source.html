8 
9 <duration_s> <= 0 means "no limit": keep sampling until this process is
10 killed (e.g. by the test script's own end-of-run cleanup), rather than
11 stopping on a fixed timer. Useful when the UE's actual traffic can outlast
12 a fixed duration -- a hard cutoff would silently stop recording while the
13 UE keeps transmitting.
14 
15 Installs a temporary iptables OUTPUT rule matching <proto> packets to
16 <ncc_ip>:<port> and reads its byte counter once per second. The counter
17 reflects L3 bytes (IP header + transport header + payload) for the iperf
18 flow only — identical in accounting to ut_app_rx, which reads raw IP packets
19 from tun0 (Layer 3).
20 
21 By default <port> is matched as the destination port (UE dialing out to a
22 port NCC listens on). Pass --sport when the UE is instead the server (e.g.
23 webpage's pull model, where NCC connects to a UE-hosted HTTP server): in
24 that case <port> is the UE's own listening port, so it shows up as the
25 *source* port on UE's outbound response packets, not the destination port.
26 
27 ue_tx uses a rolling average over the last <window_size> seconds (default 1).
28 ue_tx_long_term uses the cumulative mean from the start.
29 Both files: <unix_timestamp> <kbps>.
30 """
