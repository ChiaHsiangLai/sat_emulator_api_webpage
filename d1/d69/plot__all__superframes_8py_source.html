1 #!/usr/bin/env python3
2 """
3 Render one time-slot-allocation PNG per superframe from a beam scheduler's
4 superframe_plots/ folder.
5 
6 BeamScheduler::Schedule() (model/beamScheduler.cpp) writes one
7 "sf_<N>_TsAlloc" snapshot file per superframe into <beam scheduler log
8 dir>/superframe_plots/ -- same 7-field format as the whole-run "TsAlloc"
9 file plot_ts_alloc.py already reads, just scoped to a single superframe.
10 Rendering happens here, offline, deliberately separate from the live C++
11 scheduler thread: matplotlib/plotly rendering per superframe (potentially
12 hundreds of times over a run) is too slow to do inline in a thread whose
13 own timing this whole project has repeatedly had to protect.
14 
15 Usage:
16  python3 plot_all_superframes.py <superframe_plots_dir> [carrierKbps] [--html] [--net-config PATH]
17 
18 <superframe_plots_dir> is the folder BeamScheduler wrote sf_*_TsAlloc files
19 into (e.g. log_file/NCC/Sat_1_beamScheduler_1/superframe_plots/). Rendered
20 PNGs (and HTML, if --html) go into an "images/" subfolder of it, kept
21 separate from the raw sf_*_TsAlloc / sf_*_UT_*_reqPerRC_kbps data files.
22 --html additionally writes the interactive Plotly HTML per superframe
23 (off by default -- hundreds of HTML files is usually more than needed;
24 pass it if you specifically want to hover-inspect a particular superframe).
25 --net-config PATH points at Net_Configurations.txt so the y axis shows
26 every configured carrier (default: "data/Net_Configurations.txt", i.e.
27 run this from the mininet-v2/ project root -- see plot_ts_alloc.py's
28 net_config_path for what happens if it can't be found).
29 """
