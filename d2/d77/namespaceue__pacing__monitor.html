Detailed Description

Monitor TCP pacing_rate for a specific connection via ss -tin.

Usage:
    ue_pacing_monitor.py <output_path> <duration_s> <dst_ip> <dst_port>

Polls `ss -tin dst <dst_ip>:<dst_port>` once per second and records the
kernel-reported TCP pacing_rate for the iperf connection.

Output format: <unix_timestamp> <pacing_rate_kbps>
