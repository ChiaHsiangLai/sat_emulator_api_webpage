Detailed Description

Convert iperf2 UDP client or server output to the two-column
(unix_timestamp  rate_kbps) format expected by time_vs_data_rate_plot.py.

Usage:
    python3 parse_iperf_log.py <iperf_log> <start_time> <output_file> [window_size [apply_ma]]

    window_size : optional integer, number of seconds for centered moving-average
                  smoothing (default 1 = no smoothing).
    apply_ma    : optional 0/1 or false/true — enable moving-average (default 1).
                  Set to 0 to output raw per-second rates regardless of window_size.

Handled line formats (client and server, with or without -f m):
  Server: [ 1] 22.0000-23.0000 sec  0.191 MBytes  1.61 Mbits/sec  88.873 ms  0/98 (0%)
  Client: [  3]  0.0- 1.0 sec   128 KBytes  1.05 Mbits/sec
  Client: [  3]  0.0- 1.0 sec  0.125 MBytes  1.05 Mbits/sec

Lines may optionally be prefixed with an absolute Unix timestamp (injected by
prepend_timestamp.py).  When present the prefix is used directly as the output
timestamp instead of start_time + relative_t_end, eliminating any error from
the iperf_start_time.txt anchor.

  Prefixed: 1779699891.669040 [  5]  1.0000-2.0000 sec ...

Skipped lines: 'out-of-order' annotations, 'Server Report' headers,
               'Sent X datagrams' summaries, and full-run summaries
               (interval duration > 1.5 s treated as the final summary).
