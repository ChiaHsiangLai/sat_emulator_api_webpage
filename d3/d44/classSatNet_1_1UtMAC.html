Detailed Description

User Terminal MAC: sits between UtLlc (queues) and UtPhy (radio I/O). Handles logon, TBTP-based assigned transmission (TDMA), slotted-ALOHA random access, superframe timing, and handover. Scheduled transmits use TxScheduler (priority queue + TxThreadPool).
