Detailed Description

Renders the same live satellite/UT feed as SatelliteVisualizer
(satellite_visualizer.py) in a real browser via CesiumJS instead of a
local matplotlib window. Consumes the identical data_queue schema (see
dynamic_link_control's dat_queue.put(...) in simple_sns3_test_v14.py):
each item is
  {'sat_id', 'lat', 'lon', 'alt', 'uts_info': [{'id','lat','lon','alt','elev','status'}, ...]}

Unlike SatelliteVisualizer -- which is designed to be handed to a
separate multiprocessing.Process because matplotlib's
FuncAnimation/plt.show() blocks the whole process -- this runs entirely
in background threads of the calling process: a browser window is
already its own separate OS process, so there's nothing here that needs
isolating the same way.

Bridging mechanism: a background thread drains data_queue and writes
the accumulated state to a small JSON file; a plain local HTTP server
(same idea as the http.server usage already used elsewhere in this
project for HLS/webpage serving) serves that JSON file plus the
companion cesium_visualizer.html, which polls the JSON on a timer and
updates the Cesium entities. No websockets/extra pip dependency needed.
